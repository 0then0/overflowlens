# OverflowLens v0.2.1

A visual refresh and new validation evidence. The analysis core, input contract, mathematics and report schemas are unchanged; reports now record application version 0.2.1.

## Changes

- Redesign the interface as a dark developer console with hairline borders, graphite surfaces and one green action. The application follows the system light or dark setting. Fonts are Red Hat when installed, otherwise Inter or system fonts; nothing is loaded remotely.
- Refresh the project icon and the README screenshots.
- Add a Docker-based lab that sends the SDK workload through a digest-pinned OpenTelemetry Collector (contrib 0.163.2) and checks the OTLP output and Prometheus exposition. A pipeline with no processor preserved counts, overflow points and timestamps. A negative control that drops overflow points downstream produced a valid file with exact-looking bounds that do not apply to the original workload; OverflowLens cannot detect that loss.
- Document how to obtain usable data through the validated pipeline and what that does not guarantee.

## Download and run

Download `overflowlens-0.2.1.zip` from [GitHub Releases](https://github.com/0then0/overflowlens/releases), extract it, and change into `overflowlens-0.2.1`. Start a local HTTP server:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Open http://127.0.0.1:8080. The application, Worker and assets are in this directory; there is no nested `dist/`. Node.js, Go and Docker are not needed to use the archive. Use HTTPS for remote hosting; `file://` is unsupported. `SHA256SUMS.txt` contains the archive checksum.

For source setup, see the [README](https://github.com/0then0/overflowlens/blob/v0.2.1/README.md).

## Scope and compatibility

Supported inputs, provenance assumptions and refusals are as in [v0.2.0](https://github.com/0then0/overflowlens/blob/v0.2.1/docs/releases/v0.2.0.md). The Collector lab covers one Collector version and configuration, the pinned Go SDK and one synchronous integer counter, and was verified under Docker Desktop on macOS. It is not part of the archive or of CI. See [Collector validation](https://github.com/0then0/overflowlens/blob/v0.2.1/docs/collector-validation.md).
